# Проверка первой итерации

Выполнена 13 ноября 2026 (Asia/Yekaterinburg).

## Автоматически

- `npm run build`: TypeScript и production-сборка Vite проходят. JS около 60 КБ, gzip около 19 КБ; SVG-иконки Lucide включаются в сборку только по используемому списку.
- `npm test`: 3 проверки пройдены — восстановление/валидация данных медиатеки, режимы очереди, экранирование внешнего текста и схем ссылок на изображения.
- `npm run test:backend`: HTTP-интеграционная проверка пройдена с отдельной SQLite и локальным сервером поставщика. Подтверждены WAL, нормализация треков/альбомов/исполнителей, upsert без потери embedding, валидация запросов, 404 API и безопасный редирект превью.
- Сервер отдаёт production `client/dist` с HTTP 200 на порту 8000; `/api/health` отвечает `status=ok`, `stage=1`, `playback=preview`.

## Живые данные и браузер

- Поиск `Daft Punk`: реальные треки, альбомы и исполнители Deezer.
- Альбом Random Access Memories: получены 13 треков и обложки.
- Страница Daft Punk: получены метаданные исполнителя, доступные популярные треки и альбомы. Количество популярных треков зависит от ответа каталога.
- Прослушаны превью, наблюдались статус «Пауза», продвижение времени и автоматическое переключение очереди.
- Сохранение песни в любимое, создание плейлиста «Ночной маршрут», добавление любимой песни в плейлист; данные сохранились после перезагрузки. QA выполнялась на origin `localhost`, отдельно от пользовательского `127.0.0.1`.
- Тёмная и светлая темы переключаются; отключение анимаций меняет состояние интерфейса на `data-motion=off`.
- Экраны 320 и 390 пикселей: `main.scrollWidth === main.clientWidth`, горизонтального переполнения нет. Мобильная нижняя панель имеет высоту 58 пикселей.
- Рабочий стол 1440 пикселей: центр группы громкости и центр контейнера плеера совпадают (932.5 px при viewport 1440×1000).
- Скриншоты: `artifacts/home-desktop.jpg`, `artifacts/home-mobile.jpg` (локальные, не входят в Git).

Это эмуляция размеров браузера; физические Android/Windows приложения, реальное устройство Android, production-VPS и удалённый Telegram/LLM не проверялись. Нативные приложения пока не созданы. Перетаскивание стеклянной линзы реализовано через Pointer Events, физический жест на телефоне ещё требует проверки.

Один временный ReferenceError был зафиксирован горячим обновлением между двумя последовательными записями исходников; после завершения правки и перезагрузки медиатека отображается корректно. Это не ошибка финальной production-сборки.
