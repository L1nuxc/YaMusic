## Оставшиеся границы

Доступность полного аудио зависит от внешнего источника; отсутствие подходящей записи больше не маскируется фрагментом. Превью сохранено только для внутреннего анализа звука. Качество индивидуального подбора требует дальнейшего прослушивания; алгоритм не угадывает вкус без сигналов. Telegram, синхронизация плейлистов, DeepSeek/нейроволна, перевод, внешние импорты и crossfade не входят в завершённые исправления этого прохода.
