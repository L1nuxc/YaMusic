# Полное аудио, текст и исправления плеера

Проверка 13 ноября 2026, Asia/Yekaterinburg. Сайт остаётся локальным; нативные приложения не создавались.

## Плеер и тексты

Плеер занимает весь viewport; прокручивается только контейнер строк. Проверены desktop 1440×900 и mobile 390×844, 360×640: размер диалога равен viewport, у внешнего диалога `scrollHeight === clientHeight`. На маленьком экране управление остаётся внутри viewport.

Имя исполнителя открывает его страницу, название песни — альбом. Проверено из поиска, нижнего плеера и раскрытого экрана. Карточки альбомов и очередь также используют отдельные ссылки.

LRCLIB вернул для тестовой песни 80 строк с таймкодами. Нажатие строки 78.32 секунды перемотало аудио к 1:18 и сделало строку текущей; внешняя прокрутка осталась 0. Для превью показан текст без ложной синхронизации: положение фрагмента в оригинале неизвестно.

## Полное аудио и кэш

- Реальный тестовый трек: YouTube, около 338 секунд, 6 002 217 байт, `audio/webm`.
- Полный запрос: HTTP 200, все байты получены; после окончания `mode=full`, `cached=true`, `source=cache`.
- Из кэша `Range: bytes=1000-2023`: HTTP 206, 1024 байта, `Content-Range: bytes 1000-2023/6002217`.
- CDN читается диапазонами до 256 КиБ; при кратком обрыве чтение продолжается с последнего переданного байта. Целая песня не буферизуется в ОЗУ.
- Запись кэша фиксируется до выдачи последней порции данных: клиент вправе закончить чтение по Content-Length без отдельного EOF. Этот случай покрыт регрессионным тестом.
- LRU защищает активные чтения. Недокачанные файлы не считаются готовым кэшем. Очистка работает только со своими старыми `.part` и осиротевшими `.audio` в папке кэша.
- Два процесса yt-dlp максимум, ограниченная очередь подготовки, максимум 80 МБ на файл. Дата/название дают оценку версии, отсутствие цензуры не объявляется гарантированным.

## Проверки

`npm run build` проходит. Клиент: 5 тестов — сохранения, очередь, безопасный вывод, LRC с повторными таймкодами/offset, обычный текст без выдуманных таймкодов.

Сервер: 7 тестов — HTTP-каталог/SQLite WAL, сопоставление текста, кэш текста после отключения поставщика, Range/валидация URL, исключение неверных версий, LRU активных читателей, запись кэша до последнего байта. Проверены `npm run test:backend` и офлайн-режим Cargo.

## Ограничения

Hitmos отвечает HTTP 403, его адаптер не подключён; защита не обходится. Доступность и форматы YouTube/SoundCloud могут меняться. Если подходящей полной версии нет, используется явно обозначенный фрагмент Deezer.

Текст доступен не для каждой песни. Есть состояния для инструментальных треков, отсутствующего текста и временной ошибки с повтором. Перевод, ML-рекомендации и Telegram — следующие модули.

Мобильная компоновка проверена эмуляцией, не на физическом телефоне. Скриншот: `artifacts/player-fullscreen-mobile.jpg`.
