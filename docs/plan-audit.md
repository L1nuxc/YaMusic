# Сверка YaMusic с исходным ТЗ

Исходник: `docs/spec-original.txt`. Текущий приоритет — работающий веб-сайт; нативные клиенты остаются отдельным этапом.

| Этап | Что уже есть | Что остаётся |
|---|---|---|
| 1. Бэкенд, SQLite, каталог | Axum, SQLite WAL и миграции, каталог Deezer, поиск треков, альбомов и исполнителей | Этап закрыт |
| 2. Полный звук | SoundCloud с запасным YouTube, проверка совпадения версии, HTTP Range, дисковый LRU и предварительная загрузка | Hitmos не подключён; оценка признаков версии не гарантирует отсутствие цензуры |
| 3. Звуковые рекомендации | CLAP ONNX на CPU, 512-мерные векторы, до пяти кластеров, веса реакций, непрерывная «Моя волна», «Микс дня», любимые исполнители для холодного старта | Проверка целевой нагрузки 5–10 слушателей на VPS |
| 4. Караоке, LLM и импорт | LRCLIB, кэш и синхронизация оригинала, повтор при временном сбое. Реализован перевод через DeepSeek Flash под строками оригинала с сохранением исходных таймкодов и кэшем SQLite | MyMemory по умолчанию, DeepSeek на выбор. Работают умный поиск по Enter и подборка «Нейро-волны» по описанию. Остаются бесконечное продолжение «Нейро-волны», расширение вкуса и импорт Spotify и Яндекс Музыки |
| 5. Telegram | Web Login Widget, проверка подписи, профиль и аватар, серверная cookie-сессия; вход обязателен. Реакции, подписки и позиция воспроизведения привязаны к аккаунту | Deep Link и токены для Windows/Android. Плейлисты и история сейчас в хранилище браузера |
| 6. Клиенты | Веб-интерфейс, плеер, очередь, медиатека и плейлисты, поиск, караоке, динамические цвета и реакция на звук | Crossfade, Tauri-сборки, нативные офлайн-загрузки и фоновое воспроизведение на Android |

Сервер подключает DeepSeek через `DEEPSEEK_BASE_URL`, `DEEPSEEK_MODEL` и `DEEPSEEK_API_KEY`. Переводы кэшируются отдельно для каждого провайдера. Повторное открытие перевода из кэша не расходует квоту.
