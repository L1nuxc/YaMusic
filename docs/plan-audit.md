# Статус YaMusic

Сверка с исходным ТЗ на 14 ноября 2026 года.

| Этап | Сделано | Что осталось |
|---|---|---|
| 1. Бэкенд, SQLite и каталог | Сервер на Rust, миграции, поиск треков, альбомов и исполнителей Deezer | Основные требования этапа выполнены |
| 2. Воспроизведение | SoundCloud, YouTube как запасной источник, HTTP Range, дисковый LRU и приоритетная предзагрузка очереди | Замерить время запуска и долю ошибок на разных очередях. Hitmos не подключён |
| 3. Рекомендации | CLAP ONNX на CPU, пять кластеров вкуса, учёт реакций, «Моя волна», «Откройте новое», «Микс дня», «Микс недели», «Открытие недели», подборки по исполнителю и стилю | Проверить нагрузку на VPS и подборки на реальной истории |
| 4. Караоке, ИИ и импорт | Тексты LRCLIB, отдельный поиск по строке, перевод и кэш, импорт Spotify через OAuth или файл, вставка списка треков | Добавить фоновое расширение рекомендаций. Для Google и DeepL нужны ключи. Прямой импорт из аккаунта Яндекс Музыки не подключён |
| 5. Telegram | Веб-вход, сессии, профиль, реакции, синхронизация медиатеки, истории, настроек и активного плеера | Проверить синхронизацию на реальных устройствах. Спроектировать вход через deep link для нативных сценариев |
| 6. Клиенты | Веб-клиент, плавный переход 0–8 секунд, Windows x64 на Tauri, русская установка, локальные загрузки и код обновления | Подготовить ключ обновлятора и проверить его на двух релизах. Подпись издателя Windows и Android отложены |

Первый перенос локальных данных выполняется при входе в аккаунт с устройства, на котором собрана медиатека. Мобильный браузер участвует в синхронизации аккаунта и воспроизведения.
