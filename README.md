# YaMusic для Windows

Музыкальный клиент YaMusic для Windows x64. Для входа через Telegram и воспроизведения нужен интернет.

- [Скачать установщик](https://github.com/L1nuxc/YaMusic/releases/latest/download/YaMusic-0.1.0-windows-x64-setup.exe)
- [Скачать EXE без установки](https://github.com/L1nuxc/YaMusic/releases/latest/download/YaMusic-0.1.0-windows-x64.exe)
- [Все релизы](https://github.com/L1nuxc/YaMusic/releases)

Установщик при необходимости загружает Microsoft Edge WebView2. Для запуска отдельного EXE WebView2 должен быть установлен. Файлы первой версии без цифровой подписи.

[Открыть веб-версию YaMusic](https://yamusic.pigboss.xyz/)
